# Максик — голосовой котёнок-помощник 🐱

Рыжий котёнок, который открывает приложения, ищет ответы в интернете, говорит погоду,
шутит и управляет телефоном.

## Команды
- Приложения и сайты: «открой ютуб», «открой github.com», «открой сайт википедия».
- **Поиск в интернете:** «найди рецепт борща», «что такое радуга», «кто такой Пушкин», «расскажи про кошек» —
  Максик сам найдёт статью в Википедии, прочитает вслух начало и покажет кнопку «Читать полностью».
  Если ответа нет — откроет Google. «Загугли …» сразу открывает поиск Google в браузере.
- Погода: «погода в Москве».
- Анекдоты: «расскажи анекдот».
- Телефон: «громкость 50», «громче», «яркость 70», «темнее», «включи вибро», «режим без звука»,
  «обычный режим», «включи вайфай», «выключи блютуз», «следующий трек», «пауза», «играй».
- Общение: «молодец, Максик», «спасибо», «я тебя люблю», «как дела», «мне грустно» (утешит),
  «погладь Максика» или просто нажми на котёнка — замурлычет.
- «Молодец, Максик, держи вкусняшку» — на голову падает печенька.
- «Максик, спать» / «пора ложиться спать» — засыпает; «доброе утро, Максик» / «пора вставать» — просыпается.
- Режим «Привет, Максик» включается кнопкой в приложении.

## Голос
Максик говорит голосом Android (Google TTS) — выбирается лучший установленный русский голос, тон чуть
повышен. Чтобы звучало как можно лучше: Настройки → Язык и ввод → Синтез речи → Google → установить
русский голос высокого качества.
Мяуканье по умолчанию синтезируется в приложении. Хочешь настоящее — положи файл
`app/src/main/res/raw/meow.ogg` (или `.mp3`/`.wav`), и Максик будет мяукать им.

## Сборка APK
1. GitHub: загрузить проект → Actions → Build APK → скачать артефакт.
2. Android Studio: File → Open → Build → Build APK(s).
3. Консоль (JDK 17 + Android SDK + Gradle 8.7): `gradle assembleRelease`
